About

Software engineering, with a security habit.

Computer Engineering student, builder of small security tools, and an occasional open-source contributor. I like problems where the software and the threat model have to be designed together.

I'm a Computer Engineering graduate-in-progress at NMIET, Pune (Savitribai Phule Pune University, batch of 2026). My interest in security started with breaking things and turned into wanting to build the tooling that notices when someone else does.

Most of my work combines software engineering with security research: monitoring and threat detection, vulnerability assessment, and automation that removes repetitive work. Greywatch, my open-source SIEM, is the clearest example — it covers ingestion, normalization, detection and triage in one small system.

I also contribute to open-source projects, mostly code, tests and documentation, because reading someone else's codebase is still the fastest way to learn how software is really put together.
