Featured project

Greywatch SIEM

A small, self-hosted Security Information and Event Management platform for Linux. It pulls in SSH and sudo logs plus Suricata alerts, normalises them into events, runs detection rules, and gives you a dashboard to investigate what fired.

  • SSH authentication monitoring from the systemd journal
  • SSH brute-force detection that raises alerts with evidence attached
  • Suricata eve.json integration for alerts, DNS, HTTP, TLS and flow
  • Event normalization, ingestion and cross-event correlation into incidents
  • Cursor-based log collection with checkpointing and deduplication
  • API trust boundaries, authentication and request-size protection
  • Automated backend test coverage across the API and detection paths
